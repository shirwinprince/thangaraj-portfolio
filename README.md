# Thangaraj Chandrasekar — Professional Portfolio

A high-trust, semi-contrast portfolio website crafted for **Thangaraj Chandrasekar** (Operations & Data Analytics Specialist with 10+ years of experience in Healthcare Insurance Operations, Banking KPO, Python, SQL, and Power BI).

## Quick Start in VS Code

1. **Extract the ZIP file** and open the `thangaraj-portfolio` folder in **VS Code**.
2. Open the integrated terminal (`Ctrl + ~`) and install dependencies:
   ```bash
   npm install
   ```
3. Start the local development server:
   ```bash
   npm run dev
   ```
4. Open `http://localhost:5173` in your browser.

## Deploying to Vercel

1. Push this folder to a GitHub repository (`git init`, `git add .`, `git commit -m "Initial portfolio"`).
2. Import the repository into [Vercel](https://vercel.com).
3. Vercel automatically detects **Vite** (`npm run build`, output directory `dist`) and deploys your site with zero configuration.
